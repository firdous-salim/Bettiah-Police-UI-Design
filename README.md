# Bettiah Police Website - Frontend UI Design

A clean, accessible, and highly responsive user interface designed specifically for a law enforcement/government portal. This project focuses on delivering a structured and user-friendly experience for citizens to access critical information easily.

> ** Note on Source Code:** Due to security policies and the sensitive nature of the project domain, the source code for this repository is kept completely private. This repository serves purely as a visual portfolio to demonstrate UI/UX and frontend design capabilities.

## 🎨 Design Philosophy & Features
* **Official & Trustworthy Look:** Utilized a color palette and layout structure that reflects authority, trust, and clarity, essential for a government website.
* **100% Custom Styling:** Built completely from scratch without relying on any external CSS frameworks (like Bootstrap or Tailwind).
* **Semantic Structure:** Designed using proper HTML5 semantics for better readability and accessibility.
* **Clean UI:** Minimalist approach to ensure that important alerts and information are the primary focus for the user.

## 💻 Tech Stack
* **Markup:** HTML5
* **Styling:** CSS3 (Pure Custom CSS, No Frameworks)
* **Design Approach:** Mobile-First & Responsive Web Design
